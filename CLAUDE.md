# CLAUDE.md — Raíz del Proyecto

Este proyecto es una tesis de optimización multi-objetivo de una cadena de suministro citrícola sostenible.
Está dividido en tres modelos progresivos: consola → API → web.

## Estructura del Proyecto

```
01-console-model/   # Scripts Python directos (LGP y Epsilon-Restricción)
02-api-model/       # FastAPI que expone los solvers como REST API
03-web-model/       # Frontend Vanilla JS que consume la API
docs/               # Documentación y outputs de referencia (AMPL/CPLEX)
```
